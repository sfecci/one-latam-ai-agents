# Project 01 — AI Strategic News Dashboard

## Overview

This project was developed as part of the ONE Latam AI Agents program.

The objective was to build an AI-powered strategic news dashboard using Google Opal, creating a visual multi-step AI pipeline without traditional coding.

The system searches for relevant news on the internet, validates the results, organizes the information, and generates a professional news dashboard.

## 🎯 Project Goal

The goal of the project was to understand how AI can move beyond a simple chatbot interaction and work as a pipeline of specialized agents.

Each stage of the workflow has a specific responsibility, allowing the system to search, validate, process, and present information automatically.

## 🤖 What the AI Pipeline Does

The workflow:

1. Receives the user's preferences or news requirements.
2. Searches the internet for relevant and recent news.
3. Uses temporal grounding to prioritize current information.
4. Validates the retrieved links to reduce hallucinated or invalid URLs.
5. Processes and organizes the information.
6. Generates a conceptual image.
7. Creates a professional HTML news dashboard.

## 💡 What I Learned

One of the main lessons from this project was understanding the difference between using an AI model simply as a chatbot and designing a workflow where multiple AI steps collaborate toward a specific objective.

I also learned why validation is important when AI systems use information from the web. Generative AI can sometimes produce links or information that appears correct but does not actually exist. Adding a validation step makes the final result more reliable.

Another important concept was combining sequential and parallel steps inside an AI workflow to automate a more complex task.
