# Project 02 — AI Commercial Proposal Generator

## Overview

This project was developed as part of the ONE Latam AI Agents program.

The objective was to build an AI commercial assistant capable of transforming opportunity information into a complete business proposal using ChatGPT Work, without traditional coding.

The agent uses persistent context, business rules, and reference documents to generate proposals aligned with the company’s service catalog, pricing, templates, and visual standards.

## 🎯 Project Goal

The goal of this project was to move beyond a simple chatbot and build an AI agent with process, memory, and business rules.

The agent was designed to support the commercial proposal creation process by collecting relevant opportunity information, using company reference documents, and generating a structured proposal ready for review.

## 🤖 What the AI Agent Does

The workflow:

1. Receives information about a commercial opportunity.
2. Collects or validates the required client information.
3. Uses reference documents as context.
4. Retrieves the correct service and pricing information.
5. Applies predefined business rules.
6. Structures the commercial proposal.
7. Generates a professional proposal ready for review and delivery.

## 📚 RAG and Agent Memory

One of the main concepts explored in this project was RAG — Retrieval-Augmented Generation.

Instead of relying only on the AI model’s general knowledge, the agent uses real business documents such as:

- Service catalogs
- Pricing information
- Brand guidelines
- Commercial proposal templates
- Internal reference documents

This helps reduce generic responses and improves consistency, accuracy, and alignment with business requirements.

## 🔄 Input Modes

The agent supports two different ways of collecting information:

### Briefing Mode

Used when the salesperson already has all the information about the opportunity and can provide it directly.

### Guided Form Mode

Used when the agent needs to guide the user through the information collection process step by step.

The guided flow is divided into five stages to ensure that the necessary information is collected before generating the proposal.

## 💡 What I Learned

This project helped me understand that an AI agent is more than a conversational interface.

By combining persistent context, reference documents, instructions, and business rules, an AI system can support a complete business process.

I also learned how RAG can improve the reliability of AI-generated outputs by grounding responses in real company information instead of relying only on the model’s general knowledge.

Another important lesson was understanding how reusable AI skills can make an agent easier to replicate and adapt to other business scenarios.
